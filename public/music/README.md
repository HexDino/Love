# Nhạc nền cho LoveBox 3D

Thả các tệp MP3 của bạn vào thư mục này với **đúng tên file** dưới đây:

| Tên file                  | Bài nhạc               |
| ------------------------- | ---------------------- |
| `romantic-piano.mp3`      | Piano Lãng Mạn         |
| `music-box.mp3`           | Nhạc Hộp Yêu Thương    |
| `sunset-guitar.mp3`       | Giai Điệu Hoàng Hôn    |

## Nếu chưa có file?

Không sao. Trình phát nhạc sẽ tự động phát hiện file thiếu và chuyển sang
**link CDN dự phòng** đã khai báo trong `src/lib/constants.ts` (trường `fallback`).
Nhạc vẫn phát bình thường, chỉ là không đúng gu lãng mạn như bạn muốn.

## Mẹo chọn nhạc

- Nên chọn bản **không lời**, tiết tấu chậm, độ dài 1–3 phút.
- Nén về **128 kbps** là đủ — file nhẹ giúp trang mở nhanh hơn trên 3G/4G.
- Tránh nhạc có bản quyền nếu bạn định dùng thương mại.
- Nguồn nhạc miễn phí hợp lệ: Pixabay Music, Free Music Archive, YouTube Audio Library.
